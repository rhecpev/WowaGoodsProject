# WuwaGoods (WowaGoods)

> ⚠️ 앱 이름 오타 안내: 개발 중 오타가 발생하여 앱 내부명이 `WowaGoods` 로 되어있습니다. 정확한 이름은 `WuwaGoods` 입니다.

게임 명조의 굿즈 체크리스트 앱입니다.

## 기능

- 공식 굿즈 목록 조회 (시리즈별, 캐릭터별)
- 2차창작 굿즈 등록 및 관리
- 보유 / 미보유 / 구매예정 상태 관리
- 굿즈별 수량 기록
- 여러 굿즈 상태를 한 번에 바꾸는 다중 선택
- 시리즈 제목 검색, 캐릭터·카테고리 필터, 좌우로 밀어서 탭 이동
- 캐릭터 선호 설정
- 다크/라이트 테마 지원
- 유저 데이터 백업 및 복원
- 매일 새벽 자동 데이터 업데이트
- 알림 (수령예정일·배송·신규 굿즈)

## 설치

APK 파일을 다운로드 후 설치해주세요.
알 수 없는 출처 앱 설치 허용이 필요합니다.

알림을 받으려면 앱을 처음 켤 때 나오는 알림 권한 요청을 허용해주세요. (Android 13 이상)

## 구매예정 굿즈

- 구매예정으로 바꿀 때 구입처, 구매일, 수령예정일을 기록할 수 있습니다.
- 마이페이지 → 구매예정 굿즈에서 굿즈마다 배송 시작을 표시할 수 있습니다. 여러 개를 골라 한 번에 표시할 수도 있습니다.
- 수령예정일이 지났거나 배송 시작 후 일주일이 지난 굿즈는 빨간색으로 표시됩니다.

## 알림

| 알림 | 조건 | 주기 |
|---|---|---|
| 수령예정일 지남 | 수령예정일이 지났는데 아직 구매예정 | 지난 지 1, 4, 7…일째 (3일마다) |
| 배송 지연 | 배송 시작 후 일주일이 지났는데 아직 구매예정 | 7, 10, 13…일째 (3일마다) |
| 소식 | 선호 캐릭터 신규 굿즈, 보유·구매예정 굿즈 변경 | 데이터 업데이트로 소식이 추가될 때 |

- 알림을 누르면 해당 굿즈 또는 소식 화면으로 이동합니다.
- 알림의 **이 굿즈 알림 받지 않기**를 누르면 그 굿즈의 그 알림만 꺼집니다. 날짜를 바꾸면 다시 켜집니다.

## 데이터 업데이트

- 매일 새벽 5시쯤 백그라운드에서 캐릭터, 시리즈, 굿즈 데이터가 자동으로 업데이트됩니다. 휴대폰 절전 상태에 따라 조금 늦어질 수 있습니다.
- 앱을 켤 때는 업데이트하지 않습니다. 처음 설치했을 때만 데이터를 받습니다.
- 마지막 업데이트 시각과 변경 개수는 마이페이지에서 확인할 수 있습니다.
- 바로 업데이트하려면 마이페이지 → DB 업데이트를 눌러주세요.

## 백업 및 복원

마이페이지 → 유저 데이터에서 보유 굿즈 데이터와 2차창작 굿즈를 ZIP 파일로 백업/복원할 수 있습니다.
상태, 수량, 구매 정보(구입처·구매일·수령예정일), 배송 시작일이 함께 저장됩니다. 이전 버전에서 만든 백업도 불러올 수 있습니다.

## 변경점

업데이트 후 처음 앱을 열 때 변경점이 한 번 표시됩니다. 마이페이지 → 앱 정보 → 변경점에서 다시 볼 수 있습니다.
